The Video Downloader Plus options page gives you full control over what the extension detects, how files are saved, and how the toolbar icon behaves. To open it, right-click the Video Downloader Plus icon in your toolbar and select **Options**, or click the gear icon inside the extension popup.

## Format options

Video Downloader Plus detects video and audio streams by matching against a list of known container formats. You can enable or disable each format independently to reduce noise when browsing sites that serve a lot of media you don't care about.

### Video formats

| Format | File extensions |
|--------|----------------|
| MP4 | `.mp4`, `.m4v` |
| WebM | `.webm` |
| MKV | `.mkv` |
| MOV | `.mov` |
| TS | `.ts`, `.m2ts`, `.mts` |
| AVI | `.avi` |
| OGG | `.ogg` |
| MPEG | `.mpg`, `.mpeg` |
| WMV | `.wmv` |
| FLV | `.flv` |
| 3GP | `.3gp` |

### Audio formats

| Format | File extensions |
|--------|----------------|
| MP3 | `.mp3` |
| AAC | `.aac` |
| M4A | `.m4a` |
| FLAC | `.flac` |
| WAV | `.wav` |

<Tip>Turning off formats you never download — such as OGG or 3GP — keeps the detected streams list focused on the files you actually want.</Tip>

## Minimum file size

This setting filters out media files below a given size threshold. Small files are often ad segments, sound effects, or interface audio rather than real video content.

| Preset | Typical use |
|--------|------------|
| **10 KB** | Show nearly everything, including very short audio clips |
| **100 KB** | Remove tiny files while still catching brief video segments |
| **1 MB** | Practical default — skips ad segments and most UI audio |
| **2 MB** | Focus on substantial video files only |
| **Custom** | Type any value in MB for precise control over the threshold |

<Info>The size filter applies only to progressive downloads where the file size is available from HTTP response headers. HLS and DASH streams appear regardless of this setting because their total size is not known at detection time.</Info>

## Download settings

### Download management

Toggling download management on gives Video Downloader Plus access to the browser's download API. This enables proper file naming and lets you route downloads into a specific folder. When you turn this on for the first time, your browser will ask you to grant an optional downloads permission — accept it to activate the feature.

With download management **enabled**, files pass through the browser's download manager with accurate names and your configured path prefix applied.

With download management **disabled**, the browser opens its standard save dialog, and you choose the location each time.

### Download path

When download management is active, you can set a folder prefix that Video Downloader Plus applies to all saved files. For example, entering `Video Downloader Plus/` routes everything into a `Video Downloader Plus` subfolder inside your browser's default download directory.

<Note>The download path field only appears when download management is enabled.</Note>

## Chromecast

Enable this option to add a **Cast** button to the detected streams list in the popup. When cast support is on, you can send any detected stream directly to a Chromecast or AirPlay-compatible device without downloading the file first.

Turn it off if you don't use casting — this removes the Cast button from the interface entirely and keeps the popup layout compact.

## Badge mode

The badge mode setting controls how the Video Downloader Plus toolbar icon communicates detection status when streams are found on a page:

- **Count mode** — The icon displays the number of detected video streams as a numeric badge. Useful when you want to know exactly how many streams are available before opening the popup.
- **Dot mode** — The icon shows a simple colored dot indicator regardless of how many streams were detected. Cleaner appearance for users who only care whether streams exist, not how many.

Switch between modes in settings to match your preference.

## Theme

Video Downloader Plus's popup and options page support three appearance modes:

- **Light** — Always uses the light interface regardless of your OS setting
- **Dark** — Always uses the dark interface
- **System** — Automatically follows your operating system's light or dark mode preference

Theme selection is synced across browser profiles where you are signed into the same account.

## Website controls

### Blocking a site

Add a domain to the blocked list to stop Video Downloader Plus from monitoring network traffic or showing a detection indicator on that site. This is useful for domains where the extension consistently picks up media you have no interest in downloading.

To block a site:

1. Type the domain (for example, `example.com`) into the input field
2. Click **Add** or press Enter
3. Video Downloader Plus will exclude that domain and all its subdomains from detection immediately after saving

### Removing a blocked site

Click the **X** button next to any entry in the blocked sites list to remove it. Video Downloader Plus will resume stream detection on that domain after you save.

<Tip>Blocking ad-heavy news sites or video platform domains you visit for reasons other than downloading keeps your popup clean without disabling the extension entirely.</Tip>

## Saving your changes

Settings do not apply automatically as you adjust them. When you have finished making changes:

1. Click the **Save** button at the bottom of the options page
2. A confirmation message appears to confirm the changes took effect

If you navigate away before saving, your changes will be lost.
